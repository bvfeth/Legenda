\# 🏀 Баскетбол Самара — Тренировки по баскетболу



Современный одностраничный сайт для баскетбольной школы в Самаре.



\## 🎯 Особенности



\- ✨ Современный дизайн с glassmorphism

\- 🎨 Анимированные частицы на фоне

\- 📱 Полностью адаптивный (mobile-first)

\- ⚡ Плавные анимации и переходы

\- 🏀 Параллакс-эффект при движении мыши

\- 📊 Анимированные счётчики статистики

\- 🔍 Микроразметка Schema.org

\- 🌐 Open Graph для соцсетей

\- 🎯 Интерактивная навигация



\## 🛠️ Технологии



\- HTML5

\- CSS3 (анимации, градиенты, glassmorphism)

\- JavaScript (particles, анимации, параллакс)

\- Font Awesome 6

\- Google Fonts (Inter)
